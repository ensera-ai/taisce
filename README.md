# Taisce

Memory for agents. Entity-first retrieval on one PostgreSQL substrate, with erasure that proves
itself.

Start with [`docs/00-goals.md`](docs/00-goals.md) — what this is for, and what would prove each
goal. The roadmap is the [issue list](https://github.com/althunibat/taisce/issues).

Successor to [`althunibat/memra`](https://github.com/althunibat/memra), which is measured, working,
and the baseline this has to beat. `docs/00-goals.md` §2 says why a new codebase rather than a
refactor.
